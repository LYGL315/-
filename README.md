# 抖音视频无水印下载器
基于 **PySide6** 开发的桌面端工具，支持粘贴单条分享链接、整段复制多条分享文案，一键批量解析并下载抖音无水印视频。

> ⚠️ 免责声明：本项目**仅用于个人技术学习交流**，请勿商用、请勿批量下载他人原创视频用于侵权传播；下载内容仅限个人观看，请遵守平台用户协议与国家版权相关法律法规。

## ✨ 功能亮点
1. 兼容单链接粘贴、整段多条分享文案批量自动提取链接
2. 自动解析官方无水印视频直链，下载画质与原视频一致
3. 图形化桌面界面，操作简单无需命令行操作
4. 批量下载自动命名，方便本地整理归档
5. Windows 直接运行 EXE，无需手动配置 Python 环境

## 🖥️ 运行环境
- 系统适配：Windows 10 / Windows 11
- 发行版：直接下载 Release 中的 `.exe` 双击打开即用
- 源码运行环境：Python3.9+

## 🚀 使用教程
### 普通用户（推荐使用打包好的 EXE）
1. 进入本仓库「发布 / Releases」板块，下载最新版本压缩包并解压
2. 双击 `抖音无水印下载器.exe` 启动程序
3. 将抖音 APP 复制的分享链接/整段分享文案粘贴到输入框
4. 点击解析、下载按钮，视频自动保存至本地指定文件夹
